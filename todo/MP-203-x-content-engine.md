# MP-203 — X content engine + cheap Bluesky/Threads mirrors

- **ID**: MP-203
- **Track**: 2 — Distribution
- **Status**: todo
- **Priority**: P1 — X is the only platform currently moving
- **Depends-on**: MP-102 (plank cards are the ammunition)

## Why

X is where the audience currently responds. With MP-102 done, every plank is a
self-contained shareable unit — posting becomes assembly, not creation. Mirrors
on Bluesky/Threads cost ~ten extra minutes and hedge the platform risk.

## What

1. **Content rotation** built from what already exists: plank cards (MP-102),
   the memes Pete already reposts, Super Gramma bits, RCV explainers. A simple
   posting checklist/queue doc — not a growth-hacking machine, the site's voice
   at the site's pace.
2. Fix the vestigial follow button on index.html (currently points at
   `twitter.com/x` — the generic X account, not Pete's). Audit site ↔ profile
   linkage both directions.
3. Set up Bluesky + Threads accounts holding the name (squatting insurance even
   if rarely posted), mirror the X queue when convenient.
4. Every post links back to a plank URL — the site is the hub; platforms are
   spokes.

## Acceptance

- [ ] Site's follow/social links point at the real accounts, both directions
- [ ] Name held on Bluesky + Threads
- [ ] A month of the rotation actually posted (consistency over volume)
- [ ] Post → plank-URL click-through visible in analytics
